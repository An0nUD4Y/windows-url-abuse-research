# Windows Internet Shortcut (`.url`) catalog

**An evidence-backed catalog of the Windows Internet Shortcut (`.url`) and pinned-site (`.website`) file format: sections, keys, property bags, security behaviors, and verified specimens.**


> These notes were generated by an AI language model, with human supervision, during the research. Claims still follow the confidence labels and citations below. Specimens are copies of real files, not model output.

## Scope

Microsoft has never published a specification for the `.url` file format. This repository aggregates everything that is knowable about it: the documented COM and property-set surface (`IUniformResourceLocator`, `IPropertySetStorage`, `FMTID_Intshcut`, `FMTID_InternetSite`), reverse engineering of Microsoft's real parser (`ieframe.dll` / `shell32.dll`) and of the Wine and ReactOS reimplementations, and verbatim in-the-wild specimens, benign and malicious. Every claim carries a confidence label and a numbered citation. The [bibliography](references.md) lists each work once and indexes all 171 citation numbers.

## Responsible use

This repository is for defenders, parser authors, and format archaeologists. Every file under [`specimens/`](specimens/README.md) is stored as plain text with a `.txt` suffix, including the benign shortcuts. Windows parses a real `.url` or `.website` when a folder is merely displayed, and several benign specimens point `IconFile` at a live favicon URL. Leave the `.txt` suffix in place. The files in [`specimens/poc/`](specimens/poc/) are inert copies of real malicious shortcuts and reference real attack infrastructure. Open them in an editor, and leave the referenced hosts alone. Full warning: [specimens/README.md](specimens/README.md).

## Why this repo

- **No official spec exists.** The most-cited community references (NSIS wiki, Blake's *Unofficial Guide*) state this plainly; Microsoft documents only a COM API, not a byte layout.
- **The documented API is a subset of the on-disk reality.** Real files are serialized property stores (`[{000214A0-…}] Prop<N>=<vt>,<value>`) carrying *undocumented* property IDs — most famously `Prop3` — that no Microsoft page explains.
- **The format is an attack surface.** `.url` files are parsed at *render time* (icon resolution, property store) and at *open time* (execution context), and have been abused for NTLM hash leaks (CVE-2024-43451, CVE-2025-24054), SmartScreen bypasses (CVE-2023-36025, CVE-2024-21412), and working-directory hijacks (CVE-2025-33053). Defenses that scan only at open miss the entire first class.
- **Specimens settle arguments.** Where sources conflict (`.A`/`.W` sections, `ShowCommand=1`, `BaseURL` placement, rumored keys), this catalog rules by captured files, SDK headers, and parser source code — and labels the remainder as rumor.

## Quick reference

### Sections (condensed — full table in [docs/02-sections.md](docs/02-sections.md))

| Section | Purpose | Confidence |
|---|---|---|
| `[InternetShortcut]` | Core shortcut keys; only `URL=` is required | [Documented] |
| `[InternetShortcut.A]` / `.W` | ANSI / modified-UTF-7 shadows of the core section | [Observed] |
| `[DEFAULT]`, `[DOC#n…]` | IE frameset state (`BASEURL=`, `ORIGURL=`) | [Observed] |
| `[Bookmarklet]` | `ExtendedURL=` — full `javascript:` bookmarklet (≤5119 bytes) | [Observed] |
| `[MonitoredItem]` | IE8 Web Slice / feed monitor (`FeedUrl=`, `IsLivePreview=`, `PreviewSize=`) | [Observed] |
| `[{000214A0-…}]` | FMTID_Intshcut property set (`Prop<N>=` per PROPID; `Prop3` undocumented) | [Documented] + [Observed] |
| `[{000214A1-…}]` | FMTID_InternetSite — documented at API level, **never observed on disk** | [Documented] |
| `[{9F4C2855-…}]` | System property set (`Prop5=8,…` = AppUserModel.ID) in `.website` | [Documented] |
| `[{A7AF692E-…}]` | `.website`-only pinned-site metadata; GUID undocumented | [Observed] |
| `[{5CBF2787-…}]`, `[{B9B4B3FC-…}]`, `[{64440492-…}]` | Description / Notes / Star-rating property sets (MS KB) | [Documented] |
| `[{F29F85E0-…}]` | FMTID_SummaryInformation (Title/Subject/Author/Keywords/Comment) | [Observed] |

### Top keys (condensed — full table in [docs/03-keys.md](docs/03-keys.md))

| Key | Semantics | Notable limit / risk |
|---|---|---|
| `URL` | Target address; scheme-agnostic (`http:`, `file:`, `steam://`, `javascript:`, bare paths) | 2083 chars [Observed]; the only required key |
| `IconFile` / `IconIndex` | Icon source (ICO/DLL/EXE, local, **UNC**, or favicon URL) + zero-based index | UNC/http values trigger **render-time** network access → NTLM-leak class |
| `WorkingDirectory` | Working folder for the launched app | WebDAV value → EXE/DLL search-order hijack (CVE-2025-33053) |
| `HotKey` | `(HOTKEYF_flags << 8) \| VK` decimal launch hotkey | `HotKey=0` ubiquitous in benign files and malware alike |
| `ShowCommand` | Window show state: 3 = maximized, 7 = minimized | `ShowCommand=7` recurs in exploit specimens |
| `Modified` | 18 hex chars: byte-reversed FILETIME + checksum byte | IE4–IE6-era hallmark; absent from modern files |
| `IDList` | Shell item ID list; almost always empty on disk | Explorer prefers it when present |
| `Author` / `WhatsNew` / `Comment` / `Desc` / `Roamed` | IE4-era favorites metadata | Documented PROPIDs; no longer surfaced by modern shell UI |
| `ExtendedURL` (`[Bookmarklet]`) | Full bookmarklet script | 5119 bytes; must stay in sync with truncated `URL=` |
| `FeedUrl` / `IsLivePreview` / `PreviewSize` (`[MonitoredItem]`) | IE8 Web Slice source and preview | Note the lowercase-"rl" `FeedUrl` spelling |
| `Prop<N>=<vt>,<value>` (GUID sections) | Serialized property store: N = PROPID, vt = OLE VARTYPE | `Prop3` (VT_UI4; values 0/2/9/11/15) is undocumented; `Prop4` = PID_IS_NAME |
